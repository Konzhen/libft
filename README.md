📚 Libft – Énoncé du projet
Libft est le premier projet individuel du cursus 42. Il consiste à coder en C une bibliothèque de fonctions usuelles, que tu pourras réutiliser dans tous tes projets futurs. Ce projet vise à renforcer ta compréhension du langage C, de la gestion de la mémoire et des structures de données.​

🎯 Objectifs
Reproduire certaines fonctions de la bibliothèque standard C (libc) sans utiliser de code externe.

Respecter les normes de codage strictes de 42 (norminette).

Créer une bibliothèque statique (libft.a) réutilisable.​

🧩 Structure du projet
Fonctions de la libc
Implémentation de fonctions classiques telles que :

ft_strlen, ft_memcpy, ft_strncmp, ft_isalpha, ft_atoi, etc.​

Fonctions supplémentaires
Ajout de fonctions utiles pour les projets futurs :

ft_split, ft_strtrim, ft_itoa, ft_substr, etc.​

Fonctions bonus (listes chaînées)
Manipulation de listes chaînées via des fonctions telles que :

ft_lstnew, ft_lstadd_front, ft_lstsize, ft_lstdelone, etc.​

⚙️ Compilation
make : compile les fonctions obligatoires.

make bonus : compile avec les fonctions bonus.​
